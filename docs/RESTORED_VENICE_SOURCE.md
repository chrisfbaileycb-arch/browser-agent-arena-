# Restored Venice source

The source was extracted from the two Venice chat files supplied in this workspace. `original-venice/20260928-222545/` and `original-venice/20260928-223905/` each contain the 36 files embedded in their respective complete workspace ZIP scripts. File contents were decoded from those scripts without editing. `original-venice/SHA256SUMS` records their hashes.

The earlier chat also contains a standalone `src/services/vesselExporter.ts` with a generated `runner.ts` that calls Tavily, an optional Jev gateway, and a REST destination. Its exact text is preserved in `original-venice/standalone-runner-exporter.ts` and copied byte for byte into `src/services/veniceExporter.ts`. The active `src/services/vesselExporter.ts` packages its output alongside the later custom challenge and workflow files; it does not change the generated runner. The prior starter implementation remains at `src/services/starterExporter.ts` to preserve its browser adapter interfaces and mission files.

The original code contains fixture data, local Jev fallback behavior, and simulated arena logic. The exported runner contains network requests, but does not implement a `TRANSFORMATION` step that fills its required structured fields. Running its generated price workflow without credentials halts at `extract` with `$.sku`, `$.currency`, and `$.price` required. The example REST destinations use `.internal` names and require replacement before they can receive a real dispatch. These are properties of the source as written, not changes made during restoration.
